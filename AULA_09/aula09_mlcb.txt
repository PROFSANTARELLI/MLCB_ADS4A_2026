Aprendizado não supervisionado é um tipo de Machine Learning em que o algoritmo recebe apenas dados sem rótulos (sem respostas corretas pré-definidas)
e precisa descobrir sozinho padrões, estruturas ou agrupamentos nesses dados.

Diferença:
- Supervisionado: você mostra exemplos com a resposta certa e categorizada (ex: frase: Quero fazer um pix - categoria/intenção: pix).
- Não supervisionado: você só entrega os dados crus. O algoritmo tem que encontrar sozinho o que faz sentido.

O que faz:
1 - Agrupar dados parecidos (clustering) - Exemplo: separar clientes em grupos com comportamentos semelhantes sem você dizer quais são esses grupos.

2 - Reduzir a complexidade dos dados (redução de dimensionalidade) - Exemplo: resumir milhares de características em poucas, mantendo o essencial.

3 - Detectar anomalias - Exemplo: encontrar transações bancárias ou comportamentos que fogem do padrão normal.

4 - Descobrir relações - Exemplo: produtos que costumam ser comprados juntos.

Exemplos do dia a dia:
- Segmentação de clientes em e-commerces
- Recomendação de músicas ou filmes com base em padrões de consumo
- Compressão de imagens
- Identificação de fraudes ou comportamentos estranhos

O aprendizado não supervisionado deixa o computador explorar os dados por conta própria para revelar estruturas ocultas, sem precisar de um rótulo pré-definido..


Exemplo em código:

Exemplo 1: Agrupando clientes
Objetivo: mostrar o funcionamento básico do K-Means.

Temos clientes com duas características:
- idade
- renda
Resultado: Queremos descobrir se existem grupos de clientes com características semelhantes.


Exemplo 2: Descobrindo perfis de alunos por horas de estudo
Objetivo: Mostrar categorias por horas de estudo
Vamos utilizar:
- horas de estudo por semana
- nota média
Resultado: Queremos descobrir se existem grupos de alunos com melhores notas por ter estudado mais ou menos.








# pip install scikit-learn matplotlib

import pandas as pd
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans


# Dados: [idade, renda em milhares R$]
dados = [
    [20, 2],
    [22, 2.5],
    [25, 3],
    [45, 8],
    [48, 9],
    [50, 10]
]


# Cria o algoritmo pedindo 2 grupos
modelo = KMeans(n_clusters=2, random_state=42, n_init=10)

# O algoritmo procura os grupos automaticamente
grupos = modelo.fit_predict(dados)


# Mostra o resultado
for i, grupo in enumerate(grupos):
    print("Cliente", i + 1, "→ Grupo", grupo)


# Visualização dos grupos
plt.scatter(
    [x[0] for x in dados],
    [x[1] for x in dados],
    c=grupos
)

plt.xlabel("Idade")
plt.ylabel("Renda (milhares)")
plt.title("Agrupamento de Clientes usando o K-Means")
plt.show()







# pip install scikit-learn
from sklearn.cluster import KMeans

# [horas de estudo, nota média]
alunos = [
    [2, 5.0],
    [3, 5.5],
    [4, 6.0],
    [8, 8.0],
    [9, 8.5],
    [10, 9.0]
]


# Queremos descobrir 2 grupos
modelo = KMeans(
    n_clusters=2,
    random_state=42,
    n_init=10
)


# O algoritmo encontra os grupos
grupos = modelo.fit_predict(alunos)


# Mostra o resultado
for i, grupo in enumerate(grupos):

    print(
        f"Aluno {i + 1}: "
        f"{alunos[i]} → Grupo {grupo}"
    )


# Mostra os centros encontrados pelo algoritmo
print("\nCentros dos grupos:")

print(modelo.cluster_centers_)

Aqui aparece um conceito importante do K-Means:

modelo.cluster_centers_

São os centros dos grupos, chamados de centróides.

Por exemplo, o resultado pode indicar aproximadamente:

Grupo 0 → poucas horas de estudo + notas menores
Grupo 1 → muitas horas de estudo + notas maiores
